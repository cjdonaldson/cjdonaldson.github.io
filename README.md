# cjdonaldson.github.io

This repository started as a playground for exploring web presentation through a
personal-ish site URL. Its primary focus is now curated camping and RV content,
including itineraries, reference material, planning pages, and supporting assets.

Some camping and RV files are still being evaluated for fit and usability in the
site context. As those files are resolved and curated, they should be folded into
this repository as committed content so the repo remains the coherent home for that
material instead of scattering it across multiple repositories.

Live site: [cjdonaldson.github.io](https://cjdonaldson.github.io)
